# 📊 Гант-диаграмма — руководство и заметки
## 🔧 Описание инструмента
Вайбкод веб-приложение для построения диаграмм Ганта из CSV-файлов.  
Позволяет группировать задачи по исполнителям, редактировать сроки перетаскиванием, добавлять связи между задачами, сохранять и загружать проекты.
---
## 🚀 Быстрый старт
1. **Загрузите CSV**  
   Нажмите «📁 CSV файл» и выберите файл.  
   *Файл должен содержать заголовки (первая строка)*.
2. **Выберите столбцы**  
   После загрузки появятся выпадающие списки:
   - **Название задачи** — столбец с названиями
   - **Исполнитель** — столбец с ответственными
   - **Длительность** — столбец с числом дней
3. **Настройте параметры**
   - **Дата старта** — начало проекта
   - **Авто-связи** — автоматически связывать задачи одного исполнителя последовательно
4. **Постройте диаграмму**  
   Нажмите «🚀 Построить»
---
## 🖱️ Работа с диаграммой
| Действие | Как сделать |
|----------|-------------|
| Переместить задачу | Зажмите левую кнопку на блоке и перетащите |
| Изменить длительность | Тяните за правый или левый край блока |
| Создать связь | Нажмите на кружок в конце задачи и перетащите на другую |
| Удалить связь | Кликните на линию связи → нажмите Delete |
| Свернуть/развернуть таблицу | Нажмите кнопку **◀** или **▶** слева по центру диаграммы |
| Изменить ширину колонок | Тяните за границы заголовков в таблице задач |
---
## 💾 Сохранение и загрузка
### Сохранить проект
1. Нажмите **«💾 Сохранить»**
2. Файл сохранится с расширением `.gantt`
**Что сохраняется:**
- Исходные CSV-данные
- Позиции и длительность задач (после редактирования)
- Все связи между задачами
- Дата старта проекта
- Выбранные столбцы
- Состояние панели (свернута/развернута)
- Ширина таблицы задач
### Загрузить проект
1. Нажмите **«📂 Загрузить»**
2. Выберите ранее сохранённый `.gantt` файл
---
## 📋 Формат CSV
**Обязательные условия:**
- Первая строка — заголовки
- Разделитель — запятая (`,`) или точка с запятой (`;`) — определяется автоматически
- Длительность должна быть числом (целым или дробным)
**Пример CSV:**
``` csv
Задача,Исполнитель,Дней
Разработка схемы,Иванов,5
Разработка ПО,Петров,7
Тестирование,Сидоров,3
```

## ⌨️ Горячие клавиши

|Клавиша|Действие|
|---|---|
|`Delete`|Удалить выделенную задачу или связь|
|`F11`|Полноэкранный режим (стандартный браузерный)|

---

## 🐛 Известные особенности

- При загрузке CSV автоматически подбираются столбцы по названиям (название, исполнитель, длительность)
- Задачи одного исполнителя по умолчанию идут последовательно (если включена авто-связь)
- При сохранении проекта ширина таблицы запоминается
- После загрузки проекта состояние панели (свернута/развернута) восстанавливается
